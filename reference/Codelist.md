Codelist Note that the "@usage" argument is explicitly coded here to
suppress an error. This is most likely due to S7 class, we should
revisit this in future.

## Usage

``` r
Codelist(.data = list(),
row.names = NULL,
coding_system = character(0),
full_slug = character(0))
```

## Arguments

- .data:

  Initial data

- row.names:

  Row names

## Value

New instance of class Codelist

## Properties

- coding_system:

  String, specifying the coding system of the codelist.

- full_slug:

  slug of the codelist from OpenCodelists.
