# Download a dataset parquet and store it in the cache

Download a dataset parquet and store it in the cache

## Usage

``` r
download_tidy_source(dataset, url, version)
```

## Arguments

- dataset:

  String, dataset name

- url:

  String, download URL

- version:

  String, dataset version (included in the cached filename)

## Value

Invisible path to the cached parquet
